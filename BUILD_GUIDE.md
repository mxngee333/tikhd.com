## INTRODUCTION

**Objective**: Establish the core downloader logic using a proxy backend to bypass TikTok's CORS and CDN restrictions.

### Standalone Prompt:
> Create a TikTok video downloader using a Vite/TypeScript frontend and a Firebase Functions (Express) backend. The backend must proxy the TikTok CDN URLs to allow direct browser downloads. Use a minimalist, modern UI with a link input and a 'Download' button.

## PHASE 3: Content Scaling (SEO)
**Objective**: Build massive domain authority through a 120-post SEO blog.

### Standalone Prompt:

**Objective**: Prepare the site for manual AdSense review.

### Standalone Prompt:

## PHASE 5: Mobile Bug Fixes & UX
**Objective**: Eliminate horizontal stretching and fix common mobile browser regressions.

### Standalone Prompt:

Implement a robust 'Download Intent' using dynamic anchor tags to ensure files save directly to the gallery on iOS and Android.
