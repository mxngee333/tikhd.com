TIKHD.APP - Premium TikTok Video Downloader
==========================================

TIKHD.APP is a high-performance, high-authority web platform designed for downloading TikTok videos in HD without watermarks. It is optimized for SEO, mobile accessibility, and AdSense monetization.

TECH STACK
----------
- Frontend: TypeScript, Vite, Tailwind CSS (V4)
- Backend: Firebase Cloud Functions (Node.js 20), Express
- Hosting: Firebase Hosting
- Monetization: Google AdSense (Auto-Ads & ads.txt verified)
- SEO: Advanced Schema.org (SoftwareApplication, FAQ, Organization), 120+ Blog Posts, Dynamic Sitemap.

KEY FEATURES
------------
- HD Downloads: Direct extraction from TikTok CDN nodes.
- Premium Aesthetics: Deep Purple & Black "TikTok-inspired" theme with cinematic background bokeh.
- Ambient Immersion: Persistent "Full Site Audio" with user-controlled toggle.
- Mobile Stability: Form-based input handling and robust download intent anchors.
- SEO Domination: Integrated 120-post blog library targeting global keywords.

INSTALLATION & DEPLOYMENT
-------------------------
1. Local Environment:
   $ npm install
   $ npm run dev

2. Production Build:
   $ npm run build

3. Firebase Deployment:
   $ firebase deploy

PROJECT STRUCTURE
-----------------
/public       - Static assets (favicon, ads.txt, sitemap.xml)
/src          - Frontend source (frontend.ts, index.css, blog-data.ts)
/functions    - Backend proxy logic (Node.js/Express)
index.html    - Entry point with SEO schema and AdSense tags
